- **PR #197 — MAC17a PrepHostController cancel/leak fixes from PR #195 review — merged `0b18809` (2026-05-07).** Closes out the four Gemini review comments on PR #195. **Fix 1 (HIGH)** — `awaitCommandResult` registration silently dropped the continuation when `weakSelf` was nil (still flipped `didRegister = true`, fired `dispatch()`, and left `withCheckedThrowingContinuation` suspended forever → `CheckedContinuation` runtime trap on dealloc). New `failAllPendingForTest` internal seam mirrors the existing `pendingResultsCountForTest` pattern; new "Fix 4: failAllPending drains pending continuations" test pins the deinit drain behavior by registering a continuation via `awaitCommandResult`, calling the seam, and asserting the awaiting Task resumes with `.notRunning`.
