Partition walk: iterate parent's `Partitions[]` for first child with non-empty `MountPoint`; whole-disk fallback for pre-format raw exFAT volumes the user already had mounted. Display-name chain now skips empty strings and falls back to the mounted child's `VolumeName` (parent's is often empty post-format). **Tests:** two XML plist fixtures (`Tests/Fixtures/diskutil-list-partitioned.plist` post-format MBR/ExFAT, `Tests/Fixtures/diskutil-list-wholedisk.plist` whole-disk) + four new `PrepAppTests` cases (partitioned surfaces child mount, whole-disk falls back to parent, internal disks excluded, unmounted yields nil).
