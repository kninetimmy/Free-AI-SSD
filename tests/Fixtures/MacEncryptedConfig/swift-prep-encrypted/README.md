# MAC17 swift-prep-encrypted/ fixture

This fixture pins the **first-write encrypted-config payload** the macOS
PrepApp (`mac-prep-app/`) produces via `EncryptedConfigWriter`. Companion
to the MAC5 `csharp-encrypted/` fixture in this directory:

- `csharp-encrypted/` — pins the encrypted **blob format** (PBKDF2 +
  AES-GCM wire shape) shared across both Mac apps. Generated by the
  `mac-runner/Tests/SsdEncryptionTests` binary.
- `swift-prep-encrypted/` — **this fixture** — pins the **plaintext
  payload shape** the PrepApp's `InitialPortableConfigPayload` writes
  on first SSD setup. Different from the runtime save shape because
  it's the *initial* schema the user gets before any chat / model /
  network configuration mutates it.

## Plaintext expected after unlock

| Field                  | Expected value                          |
|------------------------|------------------------------------------|
| password               | `mac17-prep-cross-lang-fixture-pw`      |
| `OllamaPort`           | `13577`                                  |
| `NetworkModeEnabled`   | `false`                                  |
| `NetworkBindAddress`   | `127.0.0.1`                              |
| `NetworkPort`          | `41555`                                  |
| `NetworkRequireApiKey` | `true`                                   |
| `NetworkApiKey`        | `""` (empty)                             |
| `PreferredCompute`     | `cpu`                                    |
| `Models`               | `[]` (empty)                             |

The C# `MacEncryptedConfigCrossLanguageTests` decrypts this fixture
with that password and asserts those fields, proving Mac PrepApp's
first-write payload is readable by Windows Runner.

The fixture uses a non-default `OllamaPort` (13577) so the C# unlock
test can distinguish "fixture decoded successfully" from "fixture
decoded empty and PortableConfig defaults filled in 11434."

## Regenerating

If a deliberate format change ships, the fixture must be regenerated AND
a dated decision recorded in `agent_docs/project_decisions.md`. From the
repo root:

```bash
swiftc \
  mac-runner/Sources/SsdEncryption.swift \
  mac-prep-app/Sources/PrepFlowStep.swift \
  mac-prep-app/Sources/DiskutilFormatCommand.swift \
  mac-prep-app/Sources/EncryptedConfigWriter.swift \
  mac-prep-app/Tests/PrepAppTests.swift \
  -parse-as-library -target "arm64-apple-macos11.0" -O \
  -o /tmp/mac-prep-tests

/tmp/mac-prep-tests write-prep-fixture tests/Fixtures/MacEncryptedConfig/swift-prep-encrypted
```

The writer preserves `README.md` (and any sibling docs) — it only
replaces `config/`. Then `git add` the regenerated fixture and bump
the matching expected values in `MacEncryptedConfigCrossLanguageTests.cs`
if they changed.
